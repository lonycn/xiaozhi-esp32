# 2.5.24

OLED 与圆屏共用四个中文本地唤醒词：你好总管、总管总管、你好小云、小云小云。移除旧词“大冷总管”。开机提示和唤醒事件显示实际词名；播报中的防误唤醒按词匹配，停止、暂停和退出仍可使用。

沿用 MultiNet7、16 MB Flash 和各板型的 PSRAM、设备身份与联网配置。更新设备时使用同一构建的应用和资源包，以免继续从旧资源读取三词配置。

[唤醒词配置和现场验收](../daleng-wake-word.md)；[上一版记录](2.5.23.md)。

OLED Quad 和圆屏 Octal 两款 AI-LAN 固件均以 ESP-IDF 6.0.1 编译通过，已核验 2.5.24 应用描述符、16 MB 分区和资源包内四词。主机回归共 176 项，3 项因本机缺少依赖跳过；播放防误唤醒相关专项复核通过。未刷机，四词真人识别仍待实机验收。
