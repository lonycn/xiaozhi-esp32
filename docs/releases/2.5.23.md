# 2.5.23

本版将已用于实机的 2.5.23 源码归入硬件仓库，并将 `Dev` 与 `main` 合并，统一版本声明和项目说明。

## 源码基线

- OLED 基线：`671e033616ee9a628c0959a00428cd8f55d018b1`。
- 圆屏基线：`95e48d66d90de99fc0469aaa06ae1d716a6f5023`，包含上述 OLED 实现及圆屏 LAN 变体。

原开发工作树的实现已经与 OLED 基线一致，仅版本声明仍为 2.5.14。本次修正为 2.5.23，并补齐圆屏的变体配置。首次源码归档提交 `c3169fd8339babddcdd8663e8b79aa648409e6ba` 的运行时代码与圆屏基线一致。

随后合并 `main` 基线 `a73e9a7e266e3196d1368ba46c30bee0d81f0a64`，保留新增板型、唤醒词启动提示、显示情绪返回值、WebSocket Ping 调度等上游改动，并适配本地播放控制与 OLED 实现。合并后的运行时代码已有变化，需另行实机验收。

圆屏变体中重复的 16 MB Flash 和 16 MB 分区表默认项已移除，继续继承项目默认值；有效硬件配置不变。

## 内容

- OLED 黑底白色布局、居中时钟、Wi-Fi 细线图标和表情微动作。
- 补齐“大笑 / 笑死 / 微笑 / 笑一笑”等回复文字的开心表情匹配。
- 保留播报队列排空后切换聆听及自播同名唤醒过滤。
- 两种 ESP32-S3 AI-LAN 变体保留独立板型身份和 PSRAM 配置。
- 精简三个项目 README 和圆屏说明，移除宣传图片、旧教程、项目推荐列表与 Star History。

## 验证范围

- 首次源码归档：主机回归 130 项通过。
- ESP-IDF 6.0.1 / ESP32-S3：OLED 和圆屏两个 AI-LAN 变体均编译通过。
- 两个应用的程序描述符均为 `2.5.23`，Flash 为 16 MB，分别使用 Quad / Octal PSRAM。
- WebSocket 与 MQTT 传输对象均参与编译。

合并时将产品语言和唤醒词移到 `profiles/daleng-cn.defaults`，由构建及打包流程共同读取，避免上游新增的英文 / Hi ESP 默认值覆盖三条定制唤醒词。普通板型继续使用上游默认值，命令行显式选择优先。
