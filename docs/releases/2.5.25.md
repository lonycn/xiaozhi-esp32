# 2.5.25

OLED 与圆屏新增本地唤醒词「你好小智」，沿用原版专用 WakeNet 模型 `wn9_nihaoxiaozhi_tts`。你好总管、总管总管、你好小云、小云小云继续由 MultiNet7 识别。两种模型共用音频前处理，开机提示显示五个词。

安装时使用匹配的应用与资源包。新资源包含 WakeNet、MultiNet7 和 FST。详见[唤醒词配置](../daleng-wake-word.md)和[上一版记录](2.5.24.md)。

OLED 与圆屏 AI-LAN 变体已使用 ESP-IDF 6.0.1 编译通过。两份资源包内的 WakeNet 权重、索引和元信息均与圆屏原始备份一致。主机回归共 177 项，3 项因本机依赖跳过。五个词的识别效果待实机验收。
