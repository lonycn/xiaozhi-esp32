# ESP32 音声端末ファームウェア 2.5.24

ESP32-S3 の OLED 端末と円形 LCD 端末向けのカスタムファームウェアです。音声認識・対話・音声合成は [xiaozhi-server](https://github.com/lonycn/xiaozhi-server) が担当します。

現在のハードウェア、ビルド手順とソース構成は [README.md](README.md)、変更内容は [2.5.24 リリース記録](docs/releases/2.5.24.md) を参照してください。
